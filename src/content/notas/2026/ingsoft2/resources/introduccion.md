# que seria un buen desarrollo de software
el software deberia entregar la funcionalidad requerida y deberia tener atributos de calidad
- aspectos funcionales y no funcionales deberan ser correctos

atributos esenciales del buen software
- mantenibilidad
- dependabilidad y seguridad
- eficiencia
- aceptabilidad para los usuarios que lo usaran

disciplina ingenieril:
- usar teorias y metodos apropiados para resolver problemas teniendo en mente limitaciones organizaciones y financieras

# problemas generales que afectan al software
heterogeneidad:
- mas y mas, los sistemas requieren operar como sistemas distributos a traves de redes que incluyen diferentes tipos de computadoras y dispositivos mobiles

cambios de negocios y cambios sociales
- los negocios y la sociedad cambian muy rapidamente mientras las nuevas tecnologias son disponibles. deben ser capaces de cambiar su software existente y rapidamente desarrollar nuevo software

seguridad y confiabilidad

scalabilidad

# fundamentos de la ingenieria de software
- los sistemas deben ser desarrollados usando un metodo de desarrollo conocido y utilizado, hay diferentes tipos para diferentes tipos de software
- dependabilidad y performance son importantes para todos los tipos de software
- entender y administrar la especificacion y requerimientos del software es importantes
- cuando sea apropiado, se deberia reutilizar software que ya haya sido desarrollado en vez de escribir nuevo software

en desarrollo web:
- los sistemas deberan ser desarrollados y entregados incrementalmente, no es practico especificar todos los requerimientos para estos sistemas de antemano
- sistemas orientados a servicios: donde los componentes de software son servicios web stand-alone

# puntos clave
- There are many different types of system and each requires appropriate software engineering tools and techniques for their development. 
- The fundamental ideas of software engineering are applicable to all types of software system. 
- Software engineers have responsibilities to the engineering profession and society. They should not simply be concerned with technical issues. 
- Professional societies publish codes of conduct which set out the standards of behaviour expected of their members.
