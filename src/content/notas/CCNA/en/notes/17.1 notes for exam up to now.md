# Exam Review Notes (Modules 1 - 17)
A curated checklist of high-frequency concepts for the CCNA 200-301 exam:

### Addressing & Subnetting:
- **Number of assignable hosts per subnet**: Calculated using $2^h - 2$ (where $h$ is the number of host bits).
- **IPv6 Prefixes**: Standard prefix for local subnets is `/64`; ISP allocation to customer site is typically `/48`.
- **IPv6 All-Nodes Multicast**: `ff02::1` reaches all IPv6-enabled interfaces on the local link.
- **IPv6 All-Routers Multicast**: `ff02::2` reaches all IPv6 routers on the local link.

### Protocols & Transport:
- **TCP vs. UDP Headers**:
  - TCP includes Sequence Number, Acknowledgment Number, Window Size, Checksum, Urgent Pointer, and 6 control flags (20 bytes minimum).
  - UDP header is fixed at only 8 bytes (Source Port, Destination Port, Length, Checksum).
- **UDP Port Selection**: When establishing communication with a server via UDP, the client randomly selects an ephemeral source port from the private range (`49152` - `65535`).

### ICMP & Diagnostics:
- **ICMPv4 Destination Unreachable Codes**:
  - `0`: Net unreachable
  - `1`: Host unreachable
  - `2`: Protocol unreachable
  - `3`: Port unreachable
- **Cisco IOS Ping Indicators**:
  - `!`: Successful echo reply received within timeout.
  - `.`: Timed out waiting for reply.
  - `U`: Destination unreachable received from intermediate router.
  - `C`: Congestion experienced packet.

### Device Management:
- **`exec-timeout <minutes> <seconds>`**: Configurable under:
  - Console port (`line console 0`)
  - Virtual Terminal ports (`line vty 0 15`)
- **Clearing Unsaved Changes**: The `reload` command reboots the device without saving `running-config`, loading the intact `startup-config` from NVRAM.

### Switching & Buffering:
- **Switch Memory Buffering Methods**:
  - **Port-Based Memory Buffering**: Frames are stored in queues linked to specific incoming/outgoing ports.
  - **Shared Memory Buffering**: All frames are deposited into a common pool dynamically shared across all switch ports.
- **Data Link Sublayers (IEEE 802 LAN/MAN)**:
  - **LLC (Logical Link Control - 802.2)**: Communicates with upper-layer network software and identifies the Layer 3 protocol.
  - **MAC (Media Access Control - 802.3)**: Controls media access and hardware addressing.
- **Switching Forwarding Methods**:
  - **Store-and-Forward**: Receives the entire frame and computes CRC/FCS before forwarding; guarantees frame integrity.
  - **Cut-Through**:
    - *Fast-Forward*: Forwards immediately after reading the 6-byte destination MAC address (lowest latency).
    - *Fragment-Free*: Checks the first 64 bytes for collision fragments before forwarding.

### Routing Logic:
- **Path Selection**: When multiple routes to the same destination exist with the same prefix length, the router selects the route with the **lowest metric** (or lowest Administrative Distance if protocols differ).

### Internet Connectivity Types:
- **Dial-up**: Inexpensive legacy connection using analog telephone line; lowest bandwidth.
- **Cable**: Uses coaxial television cable and DOCSIS standard; high bandwidth.
- **DSL**: High bandwidth over copper twisted-pair telephone lines.
- **Satellite**: Useful in remote areas, but sensitive to line of sight and heavily wooded environments; higher latency.

# Link Aggregation Control Protocol (LACP)
- **LACP (IEEE 802.3ad / IEEE 802.1AX)**: Open-standard protocol used to bundle multiple physical Ethernet interfaces into a single logical channel (EtherChannel).
- **Advantages**:
  - Increases aggregate bandwidth between switches or servers without requiring expensive interface upgrades.
  - Provides link redundancy: if a physical link within the bundle fails, traffic dynamically fails over to remaining active links without spanning-tree reconvergence.
  - Automatically negotiates bundle configuration and detects configuration mismatches or cable faults.
