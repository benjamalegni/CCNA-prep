# Objective
- Introduce the **CCNA course** and its purpose.
- Explain **what networks are**, why they exist, and their impact on daily life.
- Introduce **basic network devices** and foundational concepts used throughout the course.

## What is CCNA?
- **CCNA (Cisco Certified Network Associate)** is an entry-level networking certification.
- Validates knowledge in:
  - Network fundamentals
  - IP connectivity
  - Network access
  - Basic security
  - Automation and introduction to modern networks
- Ideal for:
  - Students
  - IT beginners
  - Individuals targeting roles such as **IT Support, Network Technician, Junior SysAdmin**

---

## What is a Network?
- A **network** is a collection of devices connected together to:
  - Share data
  - Share resources (internet, printers, servers)
- Everyday examples:
  - Home network
  - Corporate / enterprise network
  - The Internet (a network of networks)

---

## Fundamental Network Devices

### Host / End Device
- An end device that **sends or receives data**
- Examples: PC, Laptop, Smartphone, Server

### Switch
- Connects devices **within the same local area network (LAN)**
- Main function: Forward data to the correct device within the local network

### Router
- Connects **different networks together**
- Main function: Route traffic from one network to another (e.g., LAN ↔ Internet)

---

## Network Types

### LAN (Local Area Network)
- Local Area Network
- Examples: Home, Office, School
- High speed, small geographical area

### WAN (Wide Area Network)
- Wide Area Network
- Example: The Internet
- Connects multiple LANs across large geographical distances
