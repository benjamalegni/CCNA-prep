# Network Layer Overview
The primary purpose of the Network Layer (OSI Layer 3) is to enable devices to locate each other and establish end-to-end communication across interconnected networks (the Internet).

**Network Layer Operations:**
- **Addressing End Devices**: Configures hosts with globally unique logical IP addresses.
- **Encapsulation**: Encapsulates the Transport Layer PDU into an **IP packet**, prepending an IP header containing:
  - Source IP address
  - Destination IP address
- **Routing**: Selects the optimal path and forwards packets across intermediary routers (hops) toward the destination network.
- **De-encapsulation**: When a packet arrives at the destination host, the Layer 3 engine verifies the destination IP:
  - If it matches the host's IP (or multicast/broadcast), the IP header is stripped, and the L4 PDU is handed up to the transport layer service (TCP/UDP/ICMP).
  - If it does not match, the host discards the packet.

IP headers are inspected and processed by Layer 3 devices (routers and Layer 3 multilayer switches).
IP addressing remains unchanged from source to final destination, except when modified by Network Address Translation (NAT).

## Characteristics of the IP Protocol
- **Connectionless**: No dedicated end-to-end connection is negotiated before packets are dispatched.
- **Best-Effort Delivery**: Inherent unreliability; packet delivery is not formally guaranteed at Layer 3 (reliability, retransmissions, and sequencing are delegated to Layer 4 TCP).
- **Media Independent**: Operates irrespective of the underlying physical transmission medium (copper, fiber, wireless).

# IPv4
Dotted-decimal notation composed of four 8-bit octets (32 bits total), ranging from `0.0.0.0` to `255.255.255.255`.
A **Subnet Mask** (e.g. `255.255.255.0` or `/24`) separates the network portion from the host portion.

### IPv4 Header Fields
![[Pasted image 20260425173858.png]]
- **Version**: 4-bit field identifying IP version (`0100` for IPv4).
- **Differentiated Services (DiffServ / DS)**: 8 bits for QoS traffic classification (6-bit DSCP and 2-bit ECN for congestion notification).
- **Header Checksum**: 16-bit CRC validating the integrity of the IPv4 header.
- **Time to Live (TTL)**: 8-bit hop counter decremented by 1 at every router. If it reaches 0, the packet is discarded and an **ICMP Time Exceeded** message is returned to the source (prevents routing loops).
- **Protocol**: Identifies upper-layer protocol (**ICMP = 1**, **TCP = 6**, **UDP = 17**).
- **Source IPv4 Address**: 32-bit unicast address of sending device.
- **Destination IPv4 Address**: 32-bit target address (unicast, multicast, or broadcast).
- **Identification, Flags, Fragment Offset**: Manages packet fragmentation when crossing links with smaller Maximum Transmission Units (MTUs).

#### Limitations of IPv4
- **IPv4 Address Depletion**: Finite 32-bit address space (~4.3 billion addresses).
- **Lack of True End-to-End Connectivity**: Pervasive reliance on NAT masks internal IP addresses.
- **Increased Network Complexity**: NAT table maintenance adds latency and complicates peer-to-peer protocols.

# IPv6
Employs 128-bit addresses written in hexadecimal format grouped into 8 quartets (hextets) separated by colons (e.g. `2001:db8:acad:10::10`).

**Key Improvements over IPv4:**
- Vastly expanded 128-bit address space ($3.4 \times 10^{38}$ addresses).
- Streamlined fixed 40-byte base header with fewer fields, boosting router forwarding efficiency.
- Eliminates the necessity for private-to-public NAT.
- Routers do not perform fragmentation; path MTU discovery is handled by end hosts.

### IPv6 Base Header Fields (Fixed 40 Bytes)
- **Version**: 4 bits (`0110` for IPv6).
- **Traffic Class**: 8 bits (equivalent to IPv4 DiffServ/DS).
- **Flow Label**: 20 bits; provides consistent QoS forwarding for packets belonging to the same real-time flow.
- **Payload Length**: 16 bits; size of data payload following the 40-byte base header.
- **Next Header**: 8 bits (equivalent to IPv4 Protocol field; also points to optional Extension Headers).
- **Hop Limit**: 8 bits (replaces IPv4 TTL; decremented by each router hop).
- **Source IPv6 Address**: 128 bits.
- **Destination IPv6 Address**: 128 bits.
*(Note: IPv6 eliminates the Header Checksum field to eliminate per-hop recalculation overhead).*

# How Hosts Route Traffic
A transmitting host determines packet forwarding by comparing destination IP against its own subnet mask:
1. **To Itself (Loopback)**:
   - IPv4: `127.0.0.1`
   - IPv6: `::1`
2. **To a Local Host**: Destination IP shares the same network prefix. The packet is encapsulated with the target's local MAC address via [[resources/ARP|ARP]] or [[resources/neighbor discovery|Neighbor Discovery]].
3. **To a Remote Host**: Destination IP resides on a foreign network. The frame must be addressed to the **Default Gateway** MAC address.

![[Pasted image 20260508152741.png]]

## The Default Gateway
The router interface connected to the local subnet providing egress to remote networks and the Internet:
- Possesses a local IP address within the host's subnet.
- Accepts frames from local clients and routes packets toward foreign destinations.
- Configured dynamically via DHCP / SLAAC or assigned statically.

# Introduction to Routing
When an IP packet arrives at a router interface, the router parses the destination IP address and queries its **Routing Table** to find the **Longest Prefix Match**:

![[Pasted image 20260508154521.png]]

### Routing Table Entry Types
- **Directly Connected Networks**: Subnets attached to active, enabled router interfaces (code `C` and `L` for local IP).
- **Remote Networks**: Subnets reachable through neighboring routers (learned statically or dynamically via OSPF/EIGRP/BGP).
- **Default Route (`0.0.0.0/0` or `::/0`)**: The gateway of last resort used when no specific route exists.

### Static Routing
Manually entered by an administrator.
- Syntax example: `ip route 10.1.1.0 255.255.255.0 192.168.1.2`
- Ideal for small, stub networks or default gateway routes.
- Susceptible to link failures: does not adapt automatically if a topology path fails.

![[Pasted image 20260508155052.png]]

### Dynamic Routing Protocols
Routers exchange topology and reachability updates automatically:
- Examples: **OSPF (Open Shortest Path First)**, **EIGRP**, **BGP**.
- Automatically discovers remote networks and maintains real-time convergence.
- Dynamically recalculates best paths when topology links fail.
