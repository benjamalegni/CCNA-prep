## Network and Host Portions
An IPv4 address consists of 32 bits, divided into a **network portion** and a **host portion**.
It is represented in dotted-decimal notation (four 8-bit octets separated by periods), but the boundary between network and host is evaluated at the binary level.

---

## Subnet Mask
To assign an IPv4 address to an end device, the following are required:
- **IPv4 Address**: Unique 32-bit address identifying the host.
- **Subnet Mask**: Used to identify the network portion and host portion of the address (1s represent network bits, 0s represent host bits).

### Prefix Length
The prefix length is a shorthand notation for the subnet mask (CIDR notation), indicating the total count of consecutive leading network bits (e.g., `/24` represents `255.255.255.0`).
As the prefix length increases, the number of assignable host addresses per subnet decreases.

## Network, Host, and Broadcast Addresses
Within every IPv4 network, three types of addresses exist:

1. **Network Address**:
   - Represents the entire network.
   - All host bits are set to binary `0`.
   - A device belongs to this network if:
     - It shares the same subnet mask.
     - It shares the same network bits.
     - It is located in the same broadcast domain as other hosts on that subnet.
2. **Host Addresses**:
   - Addresses assigned to end devices and interfaces.
   - The host portion contains a combination of `0`s and `1`s (neither all 0s nor all 1s).
   - E.g., for `192.168.10.0/24`, assignable host addresses range from `192.168.10.1` through `192.168.10.254`.
3. **Broadcast Address**:
   - Used to transmit packets to all hosts on the IPv4 network.
   - All host bits are set to binary `1` (e.g., `192.168.10.255/24`).
   - Cannot be assigned to an individual host.

---

## Unicast, Broadcast, and Multicast
- **Unicast**:
  - One-to-one communication between two individual network endpoints.
  - Standard IPv4 unicast host ranges span from `1.1.1.1` to `223.255.255.255` (excluding loopback and reserved ranges).
- **Broadcast**:
  - One-to-all communication transmitting a message to all devices on a subnet.
  - Processed by all hosts within the broadcast domain.
  - **Limited Broadcast**: Sent to `255.255.255.255` (flooded across the local broadcast domain; never forwarded across a router).
  - **Directed Broadcast**: Targeted to the broadcast address of a specific network (e.g., `192.168.1.255`); by default, routers do not forward directed broadcasts to prevent DoS amplification attacks.
- **Multicast**:
  - One-to-many communication delivering packets to a subscribed group of hosts.
  - Reserved range: `224.0.0.0` to `239.255.255.255`.
  - Used extensively by routing protocols like OSPF (`224.0.0.5`, `224.0.0.6`) and RIPv2 (`224.0.0.9`).

---

## IPv4 Address Types
### Public Addresses
- Globally routable over the Internet via ISP routers.

### Private Addresses (RFC 1918)
Reserved for internal enterprise and home networks; not routed across the public Internet:
- **10.0.0.0/8** (`10.0.0.0` - `10.255.255.255`)
- **172.16.0.0/12** (`172.16.0.0` - `172.31.255.255`)
- **192.168.0.0/16** (`192.168.0.0` - `192.168.255.255`)

### Internet Routing & NAT
**NAT (Network Address Translation)** translates internal private IPv4 addresses to one or more publicly registered IPv4 addresses, mitigating IPv4 address exhaustion.

---

## Special IPv4 Addresses
- **Loopback (`127.0.0.0/8` or `127.0.0.1` - `127.255.255.254`)**:
  - Typically `127.0.0.1` (`localhost`).
  - Routes traffic back to the local host's internal TCP/IP protocol stack for self-testing.
- **Link-Local (`169.254.0.0/16` or `169.254.0.1` - `169.254.255.254`)**:
  - Commonly known as APIPA (Automatic Private IP Addressing).
  - Automatically configured by Windows and other OS hosts when a DHCP server is unavailable on the network segment.

---

## Legacy Classful Addressing
Historically divided into address classes before CIDR:
- **Class A (`0.0.0.0/8` to `127.0.0.0/8`)**: Large networks with up to 16+ million hosts.
- **Class B (`128.0.0.0/16` to `191.255.0.0/16`)**: Medium-to-large networks with up to ~65,000 hosts.
- **Class C (`192.0.0.0/24` to `223.255.255.0/24`)**: Small networks with up to 254 hosts.
- **Class D (`224.0.0.0` to `239.255.255.255`)**: Multicast delivery.
- **Class E (`240.0.0.0` to `255.255.255.255`)**: Experimental and research.

# Subnetting
Subnetting divides a larger network into smaller, manageable sub-networks to reduce broadcast traffic, improve performance, and enhance security.

### Grouping Strategies:
- Subnetting by location or geographic site.
- Subnetting by departmental unit or functional group.
- Subnetting by device type (workstations, servers, printers, VoIP, management).

### Subnet Structure:
- **Subnet Address**: e.g., `10.0.0.0/24`
- **Host Range**: First and last addresses cannot be assigned to hosts. E.g., `10.0.0.1` - `10.0.0.254`
- **Broadcast Address**: e.g., `10.0.0.255`

### Key Calculation Examples:
- Subdividing `10.0.0.0/8` into `/16` creates **256 subnets** with **65,534 valid hosts** each ($2^8 = 256$, $2^{16}-2 = 65,534$).
- Subdividing `10.0.0.0/8` into `/24` creates **65,536 subnets** with **254 valid hosts** each ($2^{16} = 65,536$, $2^8-2 = 254$).
- To obtain at least 100 subnets from `172.16.0.0/16`, borrow 7 bits ($2^7 = 128 \ge 100$), yielding a new prefix of `/23`.
- To obtain at least 1,000 subnets from `10.0.0.0/8`, borrow 10 bits ($2^{10} = 1024 \ge 1000$), yielding a new prefix of `/18`.

# VLSM (Variable Length Subnet Mask)
1. Subnets do not have to be uniform in size; variable masks prevent wasting scarce IP addresses.
2. Subnets must never overlap in address space.
3. Best practice: allocate the largest subnets first, descending down to point-to-point `/30` or `/31` serial WAN links.

## Device Address Allocation
- **End-user clients**: Dynamically assigned using DHCP. If subnetting schemes change, the DHCP server pool is updated and clients renew leases.
- **Servers and peripherals**: Statically configured with predictable IP addresses.
- **Public-facing servers**: Assigned public IPv4 addresses, accessed directly or translated via NAT.
- **Intermediary network devices**: Assigned static IP addresses for centralized monitoring, management (SSH/SNMP), and security.
- **Default Gateway**: Routers and firewall interfaces have an IP address assigned per interface that serves as the exit gateway for hosts on that local subnet.
