# Identifying IPv4 Address Classes
The **first octet** (the first decimal value between 0 and 255) identifies the IPv4 class:

Reserved address ranges (cannot be assigned to host interfaces):
- `0.0.0.0 – 0.255.255.255`: Local network identifier / unassigned
- `127.0.0.0 – 127.255.255.255`: Loopback diagnostics testing

## Class A
- First octet range: **1 – 126**
- Default mask: `/8` (`255.0.0.0`)
- Designed for very large networks (16 million hosts per network).

## Class B
- First octet range: **128 – 191**
- Default mask: `/16` (`255.255.0.0`)
- Designed for medium to large networks (65,534 hosts per network).

## Class C
- First octet range: **192 – 223**
- Default mask: `/24` (`255.255.255.0`)
- Designed for small networks (254 hosts per network).

## Class D (Multicast)
- First octet range: **224 – 239**
- Reserved for multicast group addressing (no host unicast assignment).

## Class E (Experimental)
- First octet range: **240 – 254**
- Reserved for experimental and research purposes.

# Classful vs CIDR Default Masks
- **Class A**: `/8` (`255.0.0.0`) -> Range: 1–126
- **Class B**: `/16` (`255.255.0.0`) -> Range: 128–191
- **Class C**: `/24` (`255.255.255.0`) -> Range: 192–223
- **Class D**: Multicast (224–239)
- **Class E**: Experimental (240–254)

# IPv6 Quick Facts
- IPv6 addresses are **128 bits** long, represented as 8 quartets (hextets) of hexadecimal numbers separated by colons.
