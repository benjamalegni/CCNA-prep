# Initial Router Configurations
1. **Configure the device name**:
	```text
	Router(config)# hostname Router-Name
	```
2. **Secure privileged EXEC mode**:
	```text
	Router(config)# enable secret password
	```
3. **Secure user EXEC mode (Console access)**:
	```text
	Router(config)# line console 0
	Router(config-line)# password password
	Router(config-line)# login
	```
4. **Secure remote Telnet / SSH access (VTY lines)**:
	```text
	Router(config)# line vty 0 4
	Router(config-line)# password password
	Router(config-line)# login
	Router(config-line)# transport input {ssh | telnet}
	```
5. **Encrypt all plaintext passwords in the configuration file**:
	```text
	Router(config-line)# exit
	Router(config)# service password-encryption
	```
6. **Provide legal notification banner**:
	```text
	Router(config)# banner motd #delimiter message delimiter#
	```
7. **Save the configuration**:
	```text
	Router(config)# end
	Router# copy running-config startup-config
	```

### Navigation Hierarchy:
`User EXEC (>)` $\to$ `enable` $\to$ `Privileged EXEC (#)` $\to$ `configure terminal` $\to$ `Global Configuration ((config)#)`

# Interface Configuration
```text
Router(config)# interface type-and-number 
Router(config-if)# description description-text 
Router(config-if)# ip address ipv4-address subnet-mask 
Router(config-if)# ipv6 address ipv6-address/prefix-length 
Router(config-if)# no shutdown
```

- The `description` command is not required to activate an interface, but it is considered best practice for documentation.
- The `no shutdown` command enables the interface (similar to powering it on). The interface must also be physically connected to an active device to enter the `up/up` operational state.

### Verifying Interface Configurations:
```text
R1# show ip interface brief
R1# show ipv6 interface brief
```

# Lab & Additional Concepts
### Password Setup:
1. Privileged EXEC, unencrypted (legacy): `cisco`
2. Privileged EXEC, encrypted: `itsasecret`
3. Console: `letmein`

```text
Router(config)# enable password cisco  
Router(config)# enable secret itsasecret  
Router(config)# line console 0  
Router(config-line)# password letmein  
Router(config-line)# login  
Router(config-line)# exit  
Router(config)# end
```

### Backing Up Configuration to Flash:
As an added backup procedure, you can save your startup configuration file to flash. By default, the router loads the startup configuration from NVRAM, but if NVRAM becomes corrupt, you can restore it from flash:
```text
R1# copy startup-config flash
```

| Mode | Prompt |
| --- | --- |
| **User EXEC mode** | `R1>` |
| **Privileged EXEC mode** | `R1#` |
| **Global configuration mode** | `R1(config)#` |
| **Interface configuration mode** | `R1(config-if)#` |
| **Line configuration mode** | `R1(config-line)#` |
