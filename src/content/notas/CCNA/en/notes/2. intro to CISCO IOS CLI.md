## 1. What is the Cisco IOS CLI?

The Cisco IOS *Command-Line Interface* (CLI) is the primary method to interact with Cisco routers and switches to **configure, monitor, and troubleshoot the device**. It enables operators to directly execute commands, inspect interface states, and alter operational settings.

#### Methods of Accessing the CLI
Before using the CLI, you must **connect to the device**:
- **Physical Console Port**: Using a rollover cable connected to the console RJ-45 or mini-USB port.
- **SSH (Secure Shell)**: Encrypted remote CLI management access.
- **Telnet**: Legacy unencrypted remote access (insecure, sends credentials in cleartext).

#### Command Mode Hierarchy
##### User EXEC Mode:
- Initial prompt upon login.
- Allows **basic informational and troubleshooting commands** like `show`, `ping`, and `traceroute`.
- Typical prompt: `Router>`
- Does not allow altering configuration.

##### Privileged EXEC Mode:
- Administrative / privileged access level.
- Accessed from User EXEC using the command:
  `enable`
- Typical prompt: `Router#`
- Allows viewing detailed operational data (`show running-config`), managing device storage, and issuing reboot commands.
- Commands here do not alter device configuration directly; they inspect or manage state.

##### Global Configuration Mode:
- Used to **make global changes to the system configuration**.
- Accessed from Privileged EXEC:
  `configure terminal`
- Typical prompt: `Router(config)#`
- Commands applied here affect the entire device globally.

##### Sub-configuration Modes (Interface, Line, Routing, etc.)
From Global Configuration, you enter specific sub-modes:
- **Interface Configuration**: Configure physical or logical interfaces (`Router(config-if)#`).
- **Line Configuration**: Configure console, auxiliary, or VTY/remote access lines (`Router(config-line)#`).
- **Routing Protocol Configuration**: Configure OSPF, EIGRP, etc. (`Router(config-router)#`).
- **Access-List Configuration**: Configure security filtering lists (`Router(config-ext-nacl)#`).

Example entering interface configuration:
`interface GigabitEthernet0/0/1`  
Prompt: `Router(config-if)#`

##### Other Modes
- **Setup Mode**: Guided initial setup dialog prompt upon booting without a configuration.
- **ROM Monitor (ROMMON)**: Low-level diagnostic and recovery environment used when IOS cannot boot normally.

## CLI Help and Navigation
- Type `?` to **display available commands** in the current mode or check parameter syntax:
  `Router#?`  
  `Router#show ?`
- Auto-complete commands using the **TAB** key.

# Common Foundational Commands
- `show version`: Displays Cisco IOS version, hardware details, uptime, and configuration register.
- `show running-config`: Displays the active configuration in RAM.
- `show startup-config`: Displays the saved configuration in NVRAM.

### Saving Configuration
- `copy running-config startup-config` (or shorthand `copy run start`): Writes the running configuration from RAM into NVRAM so changes persist after a reboot.

### Mode Navigation
- `exit`: Drops back one level in the command hierarchy.
- `end` or `Ctrl + Z`: Returns immediately to Privileged EXEC (`Router#`).

## Privilege Levels and Security
- Commands are tied to **privilege levels** (0 to 15, where 15 is full root administrative access). Higher levels require proper authentication.

## Additional Key Concepts
### a. Pipe and Output Filtering
Filter CLI output from `show` commands using pipes:
- `show running-config | include interface`
- `show running-config | section line`
- `show running-config | begin router`

# Lab Commands Reference:

- `Ctrl + Shift + 6`: Universal Cisco break sequence (aborts pings, traceroutes, DNS lookups).
- `enable`: Enter Privileged EXEC mode.
- `configure terminal`: Enter Global Configuration mode.
- `hostname R1`: Set device hostname.
- `enable password CCNA`: Set plaintext Privileged EXEC password (weak).
- `service password-encryption`: Encrypt plaintext passwords (uses Type 7 weak reversible cipher).
- `enable secret Cisco`: Set securely hashed Privileged EXEC secret (Type 5/Type 8/Type 9).

> If both `enable secret` and `enable password` are configured, `enable secret` takes precedence and is used.

- `do <command>`: Execute Privileged EXEC commands from within Global Configuration or sub-modes (e.g. `do show ip route`).
- `copy running-config startup-config`: Save changes to NVRAM.

# Useful Operational Commands
- `banner motd "Authorized Access Only!"`: Configure Message of the Day login banner.
- `show running-config`: View active running configuration.
- `show ip interface brief`: Overview of all interfaces, assigned IP addresses, and layer 1/layer 2 status.
- `line console 0`: Select physical console port for security configuration.

# Configuration Walkthrough: Securing Device Access

### Secure Access to the Console Line
```text
S1# configure terminal
S1(config)# line console 0
S1(config-line)# password letmein
S1(config-line)# login
S1(config-line)# exit
```

### Secure Privileged EXEC Mode
```text
S1# configure terminal
S1(config)# enable password c1$c0
S1(config)# exit
```

### Encrypt Plaintext Passwords
```text
S1# configure terminal
S1(config)# service password-encryption
S1(config)# exit
```

### Configure Enable Secret
```text
S1# configure terminal
S1(config)# enable secret itsasecret
S1(config)# exit
```

### Save Configuration to NVRAM
```text
S1# copy running-config startup-config
Destination filename [startup-config]? [Enter]
Building configuration...
[OK]
```

## Configuring Management IP on a Switch (SVI)
Switches forward Layer 2 frames out-of-the-box using MAC addresses without requiring an IP address. An IP address is assigned to a Switch Virtual Interface (SVI) purely for remote management (SSH/Telnet/SNMP):

```text
S1# configure terminal
S1(config)# interface vlan 1
S1(config-if)# ip address 192.168.1.253 255.255.255.0
S1(config-if)# no shutdown
S1(config-if)# exit
S1(config)# ip default-gateway 192.168.1.1
S1(config)# exit
```
