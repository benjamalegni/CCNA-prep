# recurrent neural networks (RNN)
- process sequences step by step (token a token), sharing the same weights across time
- hidden state $h_t$ = memoria resumida del pasado: $h_t = \tanh(W_x x_t + W_h h_{t-1} + b)$
- salida por paso: $y_t = \text{softmax}(W_y h_t)$
- entrenamiento: backpropagation through time (BPTT, se "desenrolla" la red en el tiempo)
- problemas:
	- vanishing / exploding gradients -> memoria corta, no captura dependencias lejanas
	- procesamiento secuencial -> lento, no paralelizable

# LSTM cell (Long Short-Term Memory)
- variante de RNN diseñada para resolver el vanishing gradient con memoria a largo plazo
- además del hidden state $h_t$ (memoria corta) usa cell state $C_t$ (memoria larga)
- puertas (sigmoid → valores 0..1 = cuánto dejar pasar):
	- forget: decide qué olvidar de $C_{t-1}$
	- input: cuánta información nueva guardar (candidato $\tilde{C}$ via tanh)
	- output: qué parte de la memoria emitir como $h_t$
- actualización: $C_t = f_t \cdot C_{t-1} + i_t \cdot \tilde{C}_t$, $h_t = o_t \cdot \tanh(C_t)$
- variantes:
	- GRU: simplificación con 2 puertas (menos parámetros)
	- bidirectional (BiLSTM): dos pasadas (fwd + bwd) → contexto de ambos lados, mejor para NLP

# transformers
- "Attention Is All You Need" (2017): elimina la recurrencia → paralelizable y captura dependencias largas
- arquitectura encoder-decoder (original: traducción); sin recurrencia → positional encoding (sin/cos o aprendido)
- self-attention: cada token mira a todos los demás
	- query (Q), key (K), value (V) = proyecciones de la entrada
	- $\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$
	- $\sqrt{d_k}$: escala para evitar que el softmax se sature
- multi-head attention: varias cabezas en paralelo → distintos subespacios/relaciones
- cada bloque: multi-head attention → feed-forward (MLP), con Add & Norm (residual + layer norm)
- encoder: apila bloques de self-attention
- decoder: masked self-attention (no ver tokens futuros, autoregresivo) + cross-attention sobre el encoder
- bases de los modelos actuales (BERT, GPT...)
